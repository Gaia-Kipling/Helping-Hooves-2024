# Helping Hooves 2024

Helping Hooves is a university web development assignment completed in 2024.

The project involved designing and developing a website for an equine welfare organisation, Helping Hooves. The website provides information about equine rescue, adoption, surrender assistance and outreach programmes.

The project was developed as part of my university studies and demonstrates the application of front-end web development principles, including HTML, CSS, JavaScript, responsive web design, website navigation, forms and multimedia content.

## About Helping Hooves

Helping Hooves focuses on the welfare of unwanted and abused equines, including horses, donkeys, mules and zebras.

The website provides information about the organisation and its services, while giving visitors ways to learn more, make enquiries and connect with Helping Hooves.

## Main Pages

### HomePage.html

The main landing page introducing Helping Hooves and its purpose. It includes the organisation's branding, equine imagery, an embedded enquiry form and social media links.

### AboutUs.html

Provides information about Helping Hooves, its mission and its focus on the welfare of unwanted and abused equines.

### Services.html

Provides access to the main service areas:

- Equine Rescue
- Equine Adoption
- Equine Surrender
- Outreach Programs

### ContactUs.html

Provides contact information, a Google Maps location, an enquiry form and links to the organisation's social media profiles.

### News.html

Provides a dedicated section for Helping Hooves news and updates.

## Service Pages

The project includes separate pages for:

### Equine Rescue

### Equine Adoption
